# Computer Networks — IPv4 Subnetting and LAN Simulation

Laboratory 3 for the **Computer Networks** course at **Universidad de La Sabana**.

This project focuses on IPv4 subnetting, network configuration, and the simulation of LAN, WLAN, and WAN environments using **Cisco Packet Tracer**.

## 📖 About

The laboratory explores the design, configuration, and analysis of a simulated network infrastructure. It includes IPv4 addressing, VLAN segmentation, network interconnection, and the configuration of essential network services such as DHCP and DNS.

The project also examines data flow across the network and validates connectivity between devices and services through practical simulations.

## 🎯 Objectives

- Design an IPv4 addressing scheme for the network topology.
- Apply subnetting concepts to organize network segments.
- Configure Cisco switches and routers.
- Create and configure VLANs.
- Establish communication between different network segments.
- Configure LAN, WLAN, and WAN interconnections.
- Configure DHCP for dynamic IP address assignment.
- Configure DNS for name resolution.
- Simulate and analyze data flow across the network.
- Verify connectivity between devices, gateways, and network services.

## 🌐 Networking Concepts

### IPv4 Subnetting

Subnetting divides an IPv4 network into smaller logical subnetworks. It allows IP address space to be organized according to the requirements of different network segments.

### VLAN

Virtual Local Area Networks (VLANs) logically separate devices into different broadcast domains, improving network organization and traffic management.

### DHCP

The Dynamic Host Configuration Protocol (DHCP) automatically assigns IP addresses and other network configuration parameters, such as subnet masks, default gateways, and DNS server addresses.

### DNS

The Domain Name System (DNS) translates domain names and hostnames into IP addresses, allowing users and devices to access services through names instead of numerical addresses.

### LAN, WLAN, and WAN

- **LAN:** Connects devices within a local area.
- **WLAN:** Provides network connectivity through wireless communication.
- **WAN:** Connects networks across larger geographic or logical distances.

## 🔧 Laboratory Methodology

The laboratory followed these general steps:

1. Implement the network topology in Cisco Packet Tracer.
2. Configure the basic settings of the switches and router.
3. Develop the IPv4 addressing scheme.
4. Assign IP addresses to the corresponding network interfaces.
5. Create and configure the required VLANs.
6. Configure the Campus network using LAN and WLAN technologies.
7. Establish the necessary WAN interconnections.
8. Configure the DHCP service for dynamic IP assignment.
9. Configure the DNS service for name resolution.
10. Simulate and analyze the flow of data between devices and services.
11. Verify connectivity between PCs, mobile devices, gateways, and servers.

## 📊 Results and Analysis

The laboratory included the following activities and validations:

### IPv4 Addressing

An IPv4 addressing scheme was developed for the different VLANs, WAN links, and server LAN segments. The assigned addresses were configured on the corresponding devices and interfaces.

### DHCP Configuration

The DHCP service was configured to provide network parameters automatically to connected devices. The resulting IP configurations were verified on the terminal devices.

### VLAN and Inter-VLAN Connectivity

Connectivity between devices in different VLANs was tested to verify that the network configuration and routing were functioning correctly.

### DNS and Web Access

A DNS service was configured to resolve the domain name associated with the web server. Devices from the different VLANs were tested to verify access to the hosted web page through its domain name.

### Gateway Connectivity

Ping tests were performed between PCs and their gateways to verify local connectivity and access toward external networks.

### Traffic Analysis

Cisco Packet Tracer's simulation tools were used to observe and analyze the flow of data generated by the different network services.
